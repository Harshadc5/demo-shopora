# Shopora / AIORA demo — project notes

## Git commit attribution

Every git commit made in this repo must end with this exact trailer instead of
Claude's default attribution line:

```
Co-Authored-By: Harshadc5 (uniqs)
```

Note: this is not `Name <email>` format, so GitHub will not render it as a
clickable co-author credit on the commit — it will just appear as plain text
in the commit message. That's expected; the user explicitly chose this over
providing an email.
